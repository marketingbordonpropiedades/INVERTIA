# GitHub Pages Upload

Subi **solo** el contenido de esta carpeta al repo si queres publicar rapido la landing con GitHub Pages.

## Que tiene que quedar en el repo

```text
index.html
assets/
  logos/
  video/
```

## Como publicarlo

1. Borra los archivos actuales del repo si queres dejarlo limpio
2. Sube solo `index.html` y `assets/`
3. En GitHub Pages configura:
   - Branch: `main` o `principal`
   - Folder: `/(root)`
4. Espera 1 o 2 minutos y refresca

## Importante

No subas `README.md`, `docs/` ni otros archivos si queres evitar que GitHub muestre otra cosa en vez de la landing.
