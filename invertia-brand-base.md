# INVERTIA Brand Base

## Marca

- Nombre principal: `INVERTIA`
- Firma extendida observada en los logos: `INVERTIA BROKERS INMOBILIARIOS`

## Tipografia

- Tipografia principal web: `Montserrat`
- Uso recomendado para marca `INVERTIA`: `Montserrat SemiBold`
- Uso recomendado para el resto del sitio:
  - Titulos de seccion: `Montserrat SemiBold`
  - Cuerpo y textos UI: `Montserrat Regular`
  - Textos secundarios o soporte: `Montserrat Light`

## Paleta

- Negro grafito: `#1A1A1A`
- Dorado marca: `#C99A3A`
- Dorado luz: `#E3BD68`
- Blanco calido: `#F5F2EA`
- Gris medio: `#B8B8B8`
- Gris claro: `#D9D9D9`

## Direccion visual

- Estilo general: premium, moderno, sobrio, corporativo, inmobiliario
- Debe transmitir: confianza, red profesional, inversion, propiedades, Cordoba, respaldo y nivel
- Recurso visual clave: fondos oscuros con contraste calido, dorados elegantes y composicion limpia

## Criterios UI

- El negro grafito debe funcionar como base principal de interfaz y fondos premium
- El blanco calido debe usarse en textos principales y bloques de alto contraste
- El dorado marca debe reservarse para acentos, CTAs, lineas divisorias e hitos visuales
- El dorado luz sirve para brillos, gradientes leves y detalles premium
- Los grises deben sostener textos secundarios, bordes suaves y superficies neutras

## Motion

- Animaciones elegantes, lentas y con sensacion premium
- Priorizar fade, slide suave, parallax sutil y cambios de opacidad
- Evitar movimientos bruscos, rebotes o efectos demasiado tecnologicos
