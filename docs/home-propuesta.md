# INVERTIA Home Propuesta

## Objetivo general

La home debe posicionar a INVERTIA como una red inmobiliaria premium, seria y moderna para personas o equipos que quieren abrir, profesionalizar o hacer crecer su inmobiliaria con respaldo.

## Tono

- Comercial, pero sobrio
- Premium, pero cercano
- Corporativo, pero no frio
- Aspiracional, pero creible

## Estructura

1. Hero
2. Presentacion de marca
3. Beneficios de pertenecer a la red
4. Como trabajamos
5. Vision, comunidad y presencia
6. Cierre con CTA

## Lo que por ahora no entra

- Packs detallados
- Precios
- Mucho texto tecnico
- Mensajes demasiado vendedores
