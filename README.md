# INVERTIA Web

Sitio y base conceptual para la presencia digital de `INVERTIA BROKERS INMOBILIARIOS`.

## Objetivo

Construir una web premium, moderna y sobria para presentar la red inmobiliaria INVERTIA, comunicar su posicionamiento y evolucionar la propuesta junto al equipo.

## Estado actual

- Base de marca definida
- Copy inicial de home definido
- Primera landing visual montada
- Assets de logo y video organizados dentro del proyecto

## Archivo principal para visualizar

- Landing inicial: `site/index.html`

## Direccion visual

- Estilo general: premium, moderno, sobrio, corporativo, inmobiliario
- Paleta base:
  - Negro grafito `#1A1A1A`
  - Dorado marca `#C99A3A`
  - Dorado luz `#E3BD68`
  - Blanco calido `#F5F2EA`
  - Grises `#B8B8B8` y `#D9D9D9`
- Tipografia principal: `Montserrat`
